# NewsHub 产品路线图

> 本文档包含所有规划中功能的详细设计方案。
> 
> **状态说明**: 所有功能均为 ⏳ 待开发

---

## 第一阶段：内容增强（预计1-2周）

### 1.1 原文关键引用

**目标**: 在简报中保留1-2句原文金句，增强信息可信度

**展示效果**:
```
📰 标题

🔵 事件概述: ...

💬 原文引用:
"We believe this is a pivotal moment for AI safety." — Sam Altman, CEO

🟡 重要细节: ...
```

**实现方式**:
- 修改 `ai-service/config/settings.py` 中的 `PROCESS_PROMPT`
- 要求 AI 提取原文中最有价值的1-2句引用
- 前端 `BriefCard.js` 增加引用展示区块

**工作量**: 0.5天

---

### 1.2 来源可信度标识

**目标**: 让用户快速判断信息来源的权威性

**分级标准**:
| 标签 | 说明 | 示例来源 |
|------|------|----------|
| 🏛️ 官方 | 公司/政府官方发布 | OpenAI Blog, 白宫, Apple Newsroom |
| 📰 权威媒体 | 主流新闻机构 | NYT, BBC, Reuters, Bloomberg |
| 🔬 专业媒体 | 垂直领域媒体 | TechCrunch, The Verge, Ars Technica |
| 💬 社区 | Reddit, 论坛等 | r/OnePiece, Hacker News |

**实现方式**:
1. 在 `settings.py` 添加来源分级配置:
```python
SOURCE_TIERS = {
    'official': ['openai.com', 'blog.google', 'apple.com', ...],
    'mainstream': ['nytimes.com', 'bbc.com', 'reuters.com', ...],
    'specialized': ['techcrunch.com', 'theverge.com', ...],
    'community': ['reddit.com', 'news.ycombinator.com', ...]
}
```
2. 爬虫处理时根据 `source_url` 匹配分级
3. 存入数据库 `source_tier` 字段
4. 前端显示对应标签

**工作量**: 1天

---

### 1.3 Breaking News 标签

**目标**: 重要新闻红色高亮 + 置顶显示

**判断依据**（让 AI 评估）:
- 涉及重大事件（战争、灾难、重大政策变化）
- 行业巨头的重大发布（Apple/Google/OpenAI/Tesla等）
- 影响范围广（全球性事件）
- 时效性强（刚发生的突发事件）

**实现方式**:
1. 修改 `PROCESS_PROMPT`，增加重要性判断:
```json
{
  "title_zh": "...",
  "category": "...",
  "summary": "...",
  "importance": "breaking" | "high" | "normal"
}
```
2. 后端存储 `importance` 字段
3. 前端:
   - `importance: "breaking"` → 红色 🔴 标签 + 边框高亮
   - 置顶显示（排序权重提高）

**工作量**: 1天

---

### 1.4 行动建议/风险提示

**目标**: 针对商业/投资类新闻，增加决策支持信息

**适用分类**: `finance_investment`, `business_tech`, `economy_policy`

**展示效果**:
```
⚠️ 风险提示: 美联储加息可能导致科技股短期承压，关注利率敏感型持仓

✅ 行动建议: 
• 关注受影响的科技股持仓
• 考虑适度对冲策略
• 等待市场情绪稳定后再做调整
```

**实现方式**:
- 在 `PROCESS_PROMPT` 中针对特定分类增加输出要求
- 字段: `action_advice` (可选，仅特定分类生成)
- 前端仅在有该字段时显示

**工作量**: 0.5天

## 第二阶段：数据能力（预计2-4周）

### 2.1 关键数字提取 + 历史对比

**目标**: 自动提取新闻中的关键数字，并与历史数据对比

**展示效果**:
```
📊 关键数据:
• 营收: $50B (↑15% vs 上季度)
• 用户数: 2亿 (↑30% vs 去年同期)
• 股价: $180 (发布后 ↑5%)
```

**数据结构**:
```json
{
  "metrics": [
    {"name": "营收", "value": 50, "unit": "B USD", "change": "+15%", "compare": "上季度"},
    {"name": "用户数", "value": 200, "unit": "M", "change": "+30%", "compare": "去年同期"}
  ]
}
```

**实现方式**:
1. AI 提取结构化数字
2. 后端新建 `metrics` 集合，存储历史数据
3. 新数据入库时查询同实体历史，计算变化
4. 前端展示带涨跌箭头的数据卡片

**工作量**: 3-4天

---

### 2.2 背景知识 + 时间线

**目标**: 重大事件自动关联历史背景，帮助用户理解上下文

**展示效果**:
```
📚 背景:
OpenAI成立于2015年，由Sam Altman和Elon Musk等人创立。
此前已发布GPT-1/2/3/4系列，2023年ChatGPT引发全球AI热潮。

⏱️ 事件时间线:
• 2022.11 - ChatGPT发布，2个月用户破亿
• 2023.03 - GPT-4发布
• 2023.11 - GPT-4 Turbo发布
• 2024.05 - GPT-4o发布
• 2026.02 - GPT-5发布 ← 当前
```

**实现方式**:
1. 建立「实体知识库」（公司、人物、产品）
   - 可从维基百科/公司官网预填充
   - 或用 AI 动态生成并缓存
2. AI 处理时识别新闻中的实体
3. 后端查询实体知识库，拼接背景信息
4. 时间线：查询该实体相关的历史新闻

**工作量**: 5-7天（复杂度高）

**简化方案**: 先只做「该来源过去7天的相关报道」

---

### 2.3 各方观点汇总

**目标**: 对于争议性事件，汇总不同立场的观点

**展示效果**:
```
🗣️ 各方观点:
• 支持方: "这是AI发展的里程碑" — Jensen Huang, Nvidia CEO
• 反对方: "AI安全风险被严重低估" — Yoshua Bengio, AI安全研究员
• 中立方: "需要更多时间评估长期影响" — Nature 社论
```

**实现方式**:
1. 依赖「话题聚合」功能（同一事件多来源）
2. AI 分析每个来源的立场倾向
3. 归类为 支持/反对/中立
4. 提取代表性引用

**依赖**: 需要先完成话题聚合（3.1）

**工作量**: 2-3天（话题聚合完成后）

## 第三阶段：话题系统（预计4-6周）

### 3.1 话题聚合 + 相关报道

**目标**: 同一事件的多篇报道自动聚合成一个话题

**展示效果**:
```
📁 话题: OpenAI发布GPT-5 (12篇报道)

├── [🏛️ 官方] OpenAI Blog: GPT-5正式发布 (2小时前)
├── [🔬 分析] TechCrunch: GPT-5技术深度解读 (1小时前)
├── [📰 市场] Reuters: 发布后Nvidia股价涨5% (45分钟前)
├── [💬 社区] Hacker News: 开发者社区热议 (30分钟前)
└── [📰 国际] BBC: 各国政府回应 (15分钟前)
```

**技术方案**:

```
新闻入库流程:
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│  新闻入库   │ ──→ │ 计算Embedding │ ──→ │ 相似度匹配  │
└─────────────┘     └──────────────┘     └─────────────┘
                                                │
                    ┌───────────────────────────┴───────────────────────────┐
                    ↓                                                       ↓
            相似度 > 0.85                                           相似度 < 0.85
                    ↓                                                       ↓
           ┌─────────────────┐                                    ┌─────────────────┐
           │ 加入已有话题    │                                    │ 创建新话题      │
           │ topic_id = xxx  │                                    │ topic_id = new  │
           └─────────────────┘                                    └─────────────────┘
```

**数据模型**:
```javascript
// topics 集合
{
  _id: ObjectId,
  title: "OpenAI发布GPT-5",
  keywords: ["OpenAI", "GPT-5", "AI"],
  embedding: [0.1, 0.2, ...],  // 768维向量
  brief_count: 12,
  first_seen: Date,
  last_updated: Date,
  is_trending: true
}

// briefs 集合增加字段
{
  ...existing_fields,
  topic_id: ObjectId,  // 关联话题
}
```

**Embedding 方案**:
- 使用 OpenAI `text-embedding-3-small` 或
- 使用开源 `sentence-transformers` 本地计算

**工作量**: 7-10天

---

### 3.2 关键词高亮

**目标**: 用户设置关注词，在新闻中自动高亮

**使用场景**:
- 关注特定公司：Apple, Tesla, OpenAI
- 关注特定人物：Elon Musk, Sam Altman
- 关注特定技术：GPT, Transformer, 自动驾驶

**实现方式**:
1. 用户设置（需增加用户系统，或用 localStorage）
2. 前端渲染时匹配关键词
3. 匹配到的词用黄色背景高亮

**工作量**: 2天
